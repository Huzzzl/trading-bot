  criteria checked.

## Key decisions

- Preview entries are now first-class audit entries with a dedicated
  `PREVIEW_RESULT_RECORDED` type.
- Preview identity fields (`preview_id`, `plan_id`, `lifecycle_id`) must
  be non-empty strings.
- `preview_status` must equal `"PREVIEW_RENDERED"`.
- Preview safety values are fixed: `display_only=True`, `no_submit=True`,
  `broker_payload_created=False`.
- Ledger remains pure in-memory bookkeeping.
- Broker/runtime boundaries remain unimplemented.

---

## Safety invariants

- A paper order plan is not an order.
- A dry-run preview is not an order.
- A dry-run preview is not a broker payload.
- PASS is not order approval.
- PASS_DRY_RUN_ONLY permits only offline dry-run/no-submit rendering.
- PREVIEW_RESULT_RECORDED is audit bookkeeping only.
- Ledger append does not advance lifecycle.
- All five safety flags remain False:
  - `broker_calls_made`
  - `credentials_read`
  - `network_calls_made`
  - `order_action_requested`
  - `live_trading_allowed`
- Paper trading remains not approved.
- Live trading remains blocked.
- Fail closed.
